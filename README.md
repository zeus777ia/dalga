# Dalga

Ekrandaki klavye. Bir tuşa bas, renk halka halka yayılsın. Kurulum, Node, hesap yok.

## Bilgisayara al

1. Bu sayfada yeşil **Code** → **Download ZIP**
2. Zip'i aç
3. `Dalga.bat` dosyasına çift tıkla

Edge, uygulama penceresi gibi açar. İstersen o pencereyi görev çubuğuna sabitle.

Türkçe Q düzeni açık gelir. Gökkuşağı, Halka, Kor, Şimşek, Aurora var.

Razer, Logitech, Corsair tuş ışıklarını bu dosya yakmaz. O ışıklar markanın kendi programında. Dalga, bastığın tuşu ekranda yakar.
